# Phase 2: Sidebar Shortcuts - Context

**Gathered:** 2026-05-01
**Status:** Ready for planning
**Source:** User request

<domain>
## Phase Boundary

Move all user shortcuts and navigation items (profile, settings, orders, chat) to the sidebar for quick access from any page.

</domain>

<decisions>
## Implementation Decisions

### Navigation Structure
- All major navigation items should be accessible from the sidebar
- Sidebar should be visible on all pages (not just dashboard)
- Shortcuts should be available based on user role

### the agent's Discretion

- Whether to create separate pages for each section or keep them as dashboard tabs
- Exact icon choices for each navigation item
- Ordering of items in sidebar (prioritize most-used)

</decisions>

<specifics>
## Specific Ideas

**Current state:**
- Sidebar has: Home, Dashboard, Admin (admin/seller only), Login/Sign Out
- Dashboard page has tabs: Orders, Chat, Profile (within same page)

**Desired state:**
- Sidebar should show: Home, My Orders, Chat, Profile, Settings (based on role)
- Make these accessible from the main navigation, not just within dashboard

**Shortcuts to add:**
- My Orders - view order history
- Chat - real-time messaging
- Profile - user profile management
- Settings - app settings

</specifics>

<deferred>
## Deferred Ideas

- Detailed settings page beyond profile
- Order history filtering/sorting
- Advanced chat features (attachments, read receipts)

</deferred>
